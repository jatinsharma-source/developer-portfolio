# Learning Roadmap

Six-semester plan (B.Tech CSE, Batch 2024-28).

## Semester 1 — Foundations
- C programming, basic data structures, Git and GitHub workflows.

## Semester 2 — Web Basics
- HTML, CSS, JavaScript, Linux shell scripting.

## Semester 3 — Core CS
- Python, DSA, database fundamentals, REST APIs.

## Semester 4 — Applied Development
- Object-oriented programming, frameworks, version control collaboration.

## Semester 5 — Specialisation
- Backend/frontend projects, testing, Open Source contributions.

## Semester 6 — Portfolio & placements
- Capstone project, internships, interview preparation.

> Status: Semester 1 in progress.
